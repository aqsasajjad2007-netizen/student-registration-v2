# Student Registration Form

A simple and responsive Student Registration Form built using HTML and CSS.

## 📌 About the Project

This is my first front-end development project. I created this form to practice HTML forms and apply the CSS concepts I have learned while studying front-end development.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Student information form
- Profile picture upload
- Gender selection
- Date of birth
- Department and semester selection
- Country selection
- Hobbies selection
- Address field
- Submit and Reset buttons
- Responsive design

## 🎯 What I Learned

Through this project, I practiced:

- HTML form elements
- CSS selectors
- Margin and padding
- Colors and gradients
- Borders and border-radius
- Box shadows
- Form input styling
- Focus states
- Attribute selectors
- Basic responsive design
